### Look all you want. Touch nothing.

The read-only mode for AI agents in the browser. Let Claude in Chrome, ChatGPT in Chrome, Gemini in Chrome, Comet,
Dia or [any other browser agent](https://github.com/onlyreadai/onlyread#works-with) work in your real inbox,
calendar and work tools: reads pass, and every send, post, edit or delete is refused before it leaves the browser.
